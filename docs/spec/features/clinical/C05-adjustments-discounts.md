# C05 Adjustments, Discounts and Cancellations

## Purpose
Allow controlled changes after billing: discounts, cancelling a service (refund), cancelling an advance, medicine discounts. Each change needs approval to prevent cash leakage.

## Screens in current app
| Menu | Route | Content |
|---|---|---|
| Front Desk > Adjustment (hidden, from Registration "Adjustments") | /patient/adjustments-v2 | Request type: Discount, Cancel Service, Cancel Advance. Scope: All, Hospital Services, Consultant Services, Medicine. Patient search |
| Settings > Patient Discount Approval V2 | /patient/adjustments-approval-v2 | Action: Approve Discount, Approve Medicine Discount, Reject Medicine Discount, Reject Discount, Approve Cancel Services Request, Reject Cancel Services Request, Approve Advance Cancel Request, Reject Advance Cancel Request. Patient search |

## Workflow
1. Cashier opens patient, selects invoice lines, chooses request type and enters discount or cancellation (with reason).
2. Request goes to approver list.
3. Approver approves or rejects; on approval the refund/discount posts and appears in Sale Close (C07) as "Cancel Services", "Refund Services", "After Sale Close Adjustments".

## Data
Request: patient, invoice lines, type (discount, medicine discount, cancel service, cancel advance), category (hospital, consultant, medicine), amount or %, reason, requested by, status, approved by. Report "Status Wise Report" shows Normal, Discounted, Cancelled, Re Discounted with Generated By / Approved By.

## API endpoints observed
`/api/get_patients_by_type_requested_services/`, `/api/patient_service_invoice_for_approval/:id/`, `/api/product_discount/medicine_discount_requested`, `/api/patient_advances/`.

## Rebuild notes and extensions
- Use the approval engine (P05) with rules: discount % thresholds per role, auto approve below limit, CEO above.
- Reason codes (staff, charity, doctor reference, complaint, rounding) for analytics.
- Discount policies (staff family, senior citizen, charity) applied automatically.
- Refund methods (cash, card reversal, credit note) and refund vouchers.
- Real time approval via notification to approver mobile.
- Daily discount and refund report per cashier with alerts.
